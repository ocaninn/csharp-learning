# C# Learning Journey

I'm a Computing student at Dublin Business School learning C# and .NET. This repository documents my progress: each folder is a small project, with a README explaining what it does and what I learned building it — including the bugs.

## Projects

| # | Project | What it does | Concepts practised |
| --- | --- | --- | --- |
| 1 | [Shop Receipt](Shop/) | Calculates line totals, a running total and a discount | Methods, loops, `TryParse` input validation |
| 2 | [Bank Account](bankaccount/) | Menu-driven account: deposit, withdraw, check balance | Menu loops, shared state, combining conditions with `\|\|` |
| 3 | [Bank Account V2](BankAccountV2/) | The same app rebuilt around a `BankAccount` class | Classes, constructors, encapsulation, returning `bool` for success |

## Currently learning

Object-oriented programming in C#. Next up: multiple accounts with a login, and lists.

## How I work

I plan each project before coding, test edge cases (negative numbers, empty input, exact limits), and commit each working version with Git.
